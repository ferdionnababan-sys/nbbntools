Kebijakan Privasi

Halaman ini menjelaskan cara kerja pemrosesan data pada NBBNTOOLS berdasarkan fitur yang tersedia saat ini. Penjelasan dapat diperbarui jika fitur atau infrastruktur berubah.

Input tools online

Tools yang berjalan sepenuhnya di browser memproses input di perangkat pengguna. Cara kerja dapat berbeda antarfitur; periksa keterangan pada masing-masing tool dan jangan memasukkan informasi sensitif jika belum memahami pemrosesannya.

Kasir Digital dan penyimpanan lokal

Dalam versi Kasir Digital saat ini, data produk, stok, pengaturan, keranjang tersimpan, dan riwayat transaksi disimpan di penyimpanan lokal browser (localStorage) pada perangkat yang digunakan. Data tersebut tidak otomatis tersinkron ke akun, server NBBNTOOLS, atau perangkat lain. Fitur akun dan pemisahan data antar-pengguna belum tersedia.

Siapa pun yang dapat mengakses profil browser atau perangkat yang sama mungkin dapat membuka data kasir tersebut. Hindari memakai Kasir Digital untuk data rahasia di perangkat bersama, kunci perangkat Anda, dan jangan membagikan file backup sembarangan.

Fitur backup mengunduh file JSON yang dapat memuat data kasir. Simpan file backup di tempat aman. Menghapus data situs/browser atau kehilangan perangkat dapat menghilangkan data lokal; buat backup berkala dan pastikan file backup dapat dipulihkan.

Penyimpanan browser lainnya

Fitur tertentu dapat menggunakan localStorage untuk menyimpan preferensi atau data di perangkat. Data lokal browser umumnya tidak otomatis tersedia di browser atau perangkat lain.

Hosting dan layanan pihak ketiga

Saat mengakses situs, penyedia hosting dan infrastruktur web dapat memproses informasi teknis seperti alamat IP, waktu permintaan, dan informasi browser sesuai konfigurasi serta kebijakan mereka. Layanan pihak ketiga yang digunakan oleh fitur tertentu dapat memiliki kebijakan privasi sendiri.

Keamanan dan batasan

Kami berupaya memperbaiki platform secara bertahap, tetapi penyimpanan lokal bukan pengganti sistem akun dengan autentikasi dan otorisasi server. Jangan menganggap data lokal terlindungi dari orang lain yang memakai perangkat atau profil browser yang sama.

Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika cara kerja atau fitur NBBNTOOLS berubah. Gunakan informasi terbaru di halaman ini sebelum memasukkan data penting.
