Kebijakan Privasi

Halaman ini menjelaskan secara ringkas penanganan data di NBBNTOOLS.

Input tools

Tools yang sepenuhnya berjalan di browser memproses input di perangkat pengguna dan tidak memerlukan pengiriman input ke server NBBNTOOLS.

Penyimpanan lokal

Fitur seperti favorit atau preferensi dapat menggunakan localStorage browser. Data tersebut tersimpan pada perangkat pengguna.

Layanan pihak ketiga

Hosting, keamanan, analitik, atau layanan pihak ketiga yang mungkin digunakan situs dapat memiliki kebijakan sendiri.

Perubahan

Kebijakan dapat diperbarui saat fitur situs berubah.
