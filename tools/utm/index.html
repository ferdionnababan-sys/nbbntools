UTM Link Builder

Buat URL kampanye dengan parameter UTM untuk membedakan sumber, media, kampanye, dan variasi konten saat melakukan tracking.

URL akan muncul di sini.

Cara Menggunakan

  1. Masukkan URL tujuan yang diawali https:// atau http://.
  2. Isi parameter yang dibutuhkan, seperti source, medium, campaign, dan content.
  3. Pilih Buat URL, lalu gunakan hasilnya pada kampanye.

Arti Parameter

Source menunjukkan sumber traffic, Medium menunjukkan jenis media, Campaign mengelompokkan kampanye, sedangkan Content dapat membedakan variasi iklan atau konten.

Tool terkait

Untuk menyiapkan teks promosi yang memakai link kampanye, gunakan Generator Caption. Untuk merapikan data JSON yang digunakan dalam pekerjaan teknis, gunakan JSON Formatter.
