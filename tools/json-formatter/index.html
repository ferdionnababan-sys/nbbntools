JSON Formatter

Format, minify, dan validasi JSON tanpa mengirim data ke server. Berguna saat membaca konfigurasi, respons API, atau data JSON yang sulit dibaca.

Hasil akan muncul di sini.

Cara Menggunakan

  1. Tempel JSON ke kolom input.
  2. Pilih Format untuk membuat struktur lebih mudah dibaca, Minify untuk menghilangkan whitespace, atau Validasi untuk mengecek apakah JSON dapat diparse.
  3. Gunakan Salin untuk menyalin JSON yang sedang berada di kolom input.

Catatan

Tool ini menggunakan parser JSON bawaan browser. Jika JSON malformed, pesan kesalahan dari parser akan ditampilkan agar Anda dapat menemukan masalahnya. Pemrosesan dilakukan di perangkat.
