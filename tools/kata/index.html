Word & Character Counter

Analisis teks langsung di browser untuk mengetahui jumlah kata, karakter, kalimat, paragraf, dan perkiraan waktu baca.

Kata: 0 Karakter: 0 Karakter tanpa spasi: 0 Kalimat: 0 Paragraf: 0 Estimasi baca: 0 menit

Kapan Berguna?

Gunakan penghitung ini saat menyiapkan caption, artikel, tugas, naskah, atau teks yang memiliki batas panjang tertentu. Perhitungan dilakukan langsung dari teks yang Anda masukkan.

Arti Hasil

  • Kata menghitung bagian teks yang dipisahkan spasi.
  • Karakter menghitung seluruh karakter yang dimasukkan.
  • Karakter tanpa spasi mengabaikan karakter whitespace.
  • Estimasi baca menggunakan patokan sekitar 200 kata per menit.

Tool terkait

Untuk merapikan kapitalisasi, gunakan Case Converter. Untuk membuat teks promosi, gunakan Generator Caption.
